# Email Development Projects

A portfolio of responsive email builds covering promotional campaigns, transactional messages, newsletters, and reusable components.

## Project structure

- `promotional/` — product launches, sales, announcements, and campaign emails
- `transactional/` — confirmations, receipts, account alerts, and lifecycle messages
- `newsletters/` — editorial and recurring newsletter layouts
- `components/` — reusable headers, footers, buttons, content blocks, and utilities

## Goals

Each project should demonstrate:

- Responsive, mobile-first layouts
- Accessible structure and readable typography
- Email-client-compatible HTML and inline CSS
- Dark-mode-aware styling where practical
- Clear fallback behavior for unsupported features
- Tested rendering across major email clients

## Suggested project layout

```text
project-name/
├── README.md
├── src/
│   └── index.html
├── dist/
│   └── index.html
└── screenshots/
```

Add a short README to each project describing the brief, development approach, supported clients, testing notes, and any known limitations.

## Portfolio notes

Use fictional brands, original assets, or properly licensed materials. Never commit customer data, credentials, proprietary campaign content, or production mailing lists.
